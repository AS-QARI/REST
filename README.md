# REST — رست

رفيقك الشخصي للتمرين والتغذية والتقدم. تطبيق PWA بالعربي (RTL)، لمالك واحد، محلي بالكامل — كل بياناتك تُخزَّن على جهازك فقط (IndexedDB)، بدون أي خادم أو حساب سحابي.

**التطبيق الفعلي موجود بمجلد [`web/`](web/)** — هذا الملف يخص الريبو ككل فقط.

## تشغيل التطبيق محليًا

```bash
cd web
pnpm install
pnpm run dev
```

يفتح على `http://localhost:3000`.
